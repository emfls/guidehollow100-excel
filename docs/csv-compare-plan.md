# CSV 비교 도구 — 2026-11-05

사용자 목표: 100개 복제 사이트 대신 사람의 반복 작업을 끝내주는 제품을 실제 구축. 최신 우선순위: 겉모양의 고급스러움보다 사용하기 쉬운 흐름.

사용자 가설은 주문 목록과 정산 목록의 누락·추가·금액 차이를 확인하는 운영자다. 실제 수요·매출은 아직 검증되지 않았다. 기존 본사이트의 weighted-price audit는 하나의 표에 있는 수량·가격과 평균을 검산하므로 두 파일의 번호를 연결하는 이번 도구와 작업이 다르다. 기존 excel 사이트 주소·레이아웃·배포를 재사용한다.

## 이번 구현
- /tools/csv-compare/: 샘플 즉시 실행 → CSV 파일 2개 선택 → 번호 열·선택 금액 열 → 차이 확인 → 전체 결과 CSV 저장.
- 번호는 원본 문자열을 정확히 비교. 빈 번호·중복 번호·잘못된 금액은 검토 대상으로 분리. 다른 열과 실제 입금 여부는 판단하지 않음.
- 금액은 소수 둘째 자리까지 정수 단위로 계산. 기준·비교 합계는 원본 각 파일의 유효 금액을 합산하고 중복 포함·일부 합계 여부 고지.
- UTF-8/쉼표 CSV, 파일당5MB/20,000개 데이터 레코드/100열. XLSX·OCR·외부 전송·계정·결제 제외.
- 브라우저 메모리만 사용, 파일의 내용·이름을 URL·로그·분석에 전송하지 않음. 도구 페이지 외부 배너 제외.
- 모든 동적 문구는 textContent/Option으로 렌더링. 결과 CSV의 수식 위험 값 보호. 파일 읽기 중 변경/초기화 시 이전 요청을 폐기.

## 검증
파서·금액·중복·누락·다운로드 안전성의 Node 테스트, Astro 빌드, 독립 검수, 모바일/데스크톱 실제 파일·샘플·다운로드·실패 입력·초기화 검증 후 배포. 공개 HEAD/Pages/HTTP/기능 확인 결과는 release-report.md에 기록.
